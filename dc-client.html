Дополнительные поля SA

Любое поле протокола SA по номеру. Название подставится само. «HEX» — значение передаётся HEX-строкой и превращается в байты.

Параметры запроса
Секунды. 0 — ждать бесконечно. Вендор рекомендует 180.
Пусто — новый на каждый запрос. Повтор закрытой сессии даст ошибку 17.
Строго A.B.C.D:порт. Имя хоста DC молча проигнорирует. Мост paxbridge — 127.0.0.1:27016.

  Страница работает прямо из файла: DC разрешает кросс-доменные запросы (Access-Control-Allow-Origin: *).

  Тела запросов уходят в windows-1251, как ждёт DC. Описание полей и операций — в README, раздел «HTTP API DualConnector».
